# 中豆黑体 Zhongdou Sans

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="./images/demo.png">
  <img src="./images/demo.png">
</picture>

分生自[煮豆黑体](https://github.com/Buernia/Zhudou-Sans)，后者三年无更新。原字体衍生自 [Noto Sans](https://github.com/googlefonts/noto-fonts) 和[思源黑体](https://github.com/adobe-fonts/source-han-sans)，支持中日韩标点、全角字母、全角数字及一些特殊符号。标点造型主要来源于 Noto Sans，可以为类似风格的西文字体带来更加协调的中外文混排效果。

本字体为可变字体，支持字重无级变化，同时提供对应思源黑体7个字重的静态版本。

本黑体特色在于，区域（locl）为 zh-cn 时，华语标点符号依然一律按 zh-tw 处理即居中，以满足我汉字美学追求。民国初胡适等人推广的标点符号本来也一度贯彻这美学，可惜后来陆规不懂这些，生搬硬套符合基线美学的西文标点符号。后者特征是大多标点符号居左下且不方正，抛弃了形似古代说文解字唯二符号之钩识号的直角引号，改用边角对齐的西式弯引号；引进了俄语的书名号。

其字体名意外地有一彩蛋：豆刚好与「读」谐音，后者有一古义，即逗号。

可与更纱黑体一同使用。

## 方正中宫气连美学

我可以让人智搬来一大群古代书法家帮我背书：

> 四面停勻，八邊具備，短長合度，粗細折中。心眼准程，疏密欹正。⸺傳・歐陽詢〔八訣〕

> 九宮：八面點畫皆拱中心。⸺元・陳繹曾〔翰林要訣・第九方法〕

> 凡字無論疏密斜正，必有精神挽結之處，是為字之中宮。⸺清・包世臣〔藝舟雙楫・述書〕

> 每三行相並至九字，又為大九宮，其中一字即為中宮，必須統攝上下四旁之八字，而八字皆有拱揖朝向之勢。⸺清・包世臣〔藝舟雙楫・述書〕

> 字之體勢，一筆而成，偶有不連，而血脈不斷。⸺唐・張懷瓘〔書斷〕

> 上下連延，左右顧矚，八面四方，有如佈陣。⸺明・解縉〔春雨雜述〕

汉字天生方正，点画布于九宫，四面停匀。陈绎曾所谓「八面点画皆拱中心」，道破了方块字的向心结构。不过这「中心」并非几何正中⸺〔翰林要诀〕旧注特意申明「中心者，非以一笔为中心也」；包世臣也说中宫是「精神挽结之处」，有在实画、有在虚白；刘熙载更说主笔或在字心、或在四维四正，是谓「活中宫」。中宫说的是重心，不是圆心。

但正因如此，居中标点反而更站得住：一个字的点画无论疏密斜正，都向格内收拢挽结，视觉重心总在格中一带。居左下的点号却落在八面点画所拱的结构之外，挂在字与字之间的虚白边上，重心外逸。唯有居中的点号方正饱满、与字同格，分享汉字的向心结构，而非游离其外。

汉字排版讲究行气。张怀瓘论草书一笔书，「偶有不连，而血脉不断」；解缙论一篇章法，「上下连延，左右顾瞩」；〔八诀〕同段所谓「东映西带，气宇融和」，说的也是这种字际承接。行气贵在承接，而非排成直线⸺包世臣恰恰讥笑过「上下直如贯珠，而势不相承」的字。所以他把中宫从单字推到字际：三行九字之间，亦有统摄四旁、拱揖朝向的「大中宫」。无论横排竖排，阅读视线都沿字心连线移动。居中标点守在这条视线上，前后承接，气脉不断；居角标点则把视线往格角拽，造成错位与塌陷。标点符号的出现是为了断句，但在视觉上，它不该截断气流。

## 基线美学

西方文字多为表音文字，词长不定，空格就是断词用的点号。〔汉字与中华文化十讲〕也说英文是一维文字，汉字是二维文字。华语人可试想小时候练习拉丁字母书写时，用的练习稿是不是有四条线？拉丁字母的主体和大多标点符号稳稳立在从上往下数的第三条线即基线上，随便倾斜或加粗，词长可长可短，也可以在连字上玩出花样来，反正有空格和四线兜底。在和练习华文书写的田字格字帖完全不一样，没人想在一个格子里让汉字倾斜、缩到一角、出格、连字吧。所以说在华文里混用陆规西式标点符号，就好比在田字格字帖书写英文，或是在四线纸书写华文，不伦不类。我很早就对「中文斜体」和陆规引进的西式标点符号嗤之以鼻了，把基线美学套到汉字上，没啥意义。

## 大挪移

凡是利好我美学且不符合陆规的标点符号，我也要挪用。

* 间隔号不用又窄又小的·（`U+00B7` MIDDLE DOT），用方正且较满格的・（`U+30FB` KATAKANA MIDDLE DOT）。有人嫌它是日文符号并不用，我没这禁忌。华语就引进了一大堆和制汉语词，本文所用的「符号」一词就是。
* 用六角符号即龟甲括〔〕代替书名号《》。龟甲括因形似龟甲六边而得名，方正饱满，像两片合拢的甲骨；书名号来自俄语，我总觉得和汉字不搭。
* 一律用直角引号代替西式弯引号。
* 破折号用真正的单码位双宽字符⸺（`U+2E3A` TWO-EM DASH），代替由两个单码位单宽字符组成的破折号——。煮豆黑体竟然也收录了这个，它没有在文档提到这点。
* 无论是陆规还是台规，省略号或删节号都由两个省略号（…，`U+2026` Ellipsi）组成，这就尴尬了，因为机器很难判断这个到底是该居中的华文符号，还是该居底的符号。于是哪怕用中豆字体，访问英语网站，其优先级可能会被排在该网站指定的英语字体后面，结果哪怕在该网站输入华文，省略号会被渲染成其网站指定英语字体且居底。有个绝对居中的⋯（`U+22EF` MIDLINE HORIZONTAL ELLIPSIS），虽说是数学符号，但 Unicode 官方也承认了[东亚用它作为居中符号的排版现象](https://github.com/w3c/clreq/issues/432)：「U+22EF MIDLINE HORIZONTAL ELLIPSIS has also become popular for the midline ellipsis in East Asian typography」。中豆黑体姑且收录之。

## 与煮豆黑体的差异

中豆黑体保留原字体的字形设计，但调整了以下默认排版行为：

* 将弯引号 `‘’“”` 的半角字形直接设为 Unicode 字符映射（`cmap`）中的默认字形，不借用任何 OpenType 功能。`fwid` 可改用全角字形，`pwid` 可改用比例宽度字形；开关 `ccmp` 不会改变引号宽度。
* 陆规（`ZHS`）在 `locl` 中复用台规（`ZHT`）的居中标点查找，使陆规文本默认使用居中标点；`vert` 则在默认语言与陆规文本中保留这些标点的居中形式，同时不改变其他地区的竖排规则。
* 对居中点号作光学校正，并将龟甲括与直角引号的墨迹在全部字重中移到全角字身的横向中心；由其构成的闭括号和竖排字形会同步归中，字身宽度保持不变。
* 保留 `halt`、`vhal`、`kern`、`vkrn` 功能标签以兼容应用程序，但清空其查找列表，因此字体不会自动压缩或挤移横排、竖排标点。
* 已修正[行高问题](https://github.com/Buernia/Zhudou-Sans/issues/7)。

## 字符支持

* 现代中日韩标点符号，包括间隔号・、直角引号「」、单码位双字宽字符破折号⸺、和六角括号〔〕。
* ⋯（`U+22EF` MIDLINE HORIZONTAL ELLIPSIS），单码位单字宽（full-width），可以作为华语省略号使用，虽然这违背了其数学语义。
* 古汉语钩识号（𖿢，`U+16FE2`）和重文号（𖿣，`U+16FE3`）
* 全角字母、数字
* 7个知识共享（Creative Commons）许可图标（⊜🄍🄎🄏🅭🅮🅯，`U+229C`、`U+1F10D`—`U+1F10F`、`U+1F16D`—`U+1F16F`）
* 6个中国传统吉祥图案（🉠🉡🉢🉣🉤🉥，`U+1F260`—`U+1F265`）

⚠**注意：本字体不包含汉字、假名、谚文、一般西文和数字，请和其他字体搭配使用。**

## 排版功能

本字体支持以下 OpenType 排版特性：

* **自选连字**（`dlig`）

  将「？？」「？！」与「！？」「！！」组合成「⁇」「⁈」与「⁉」「‼」合字。可在软件 OpenType 功能菜单中选择「自由连字」（Adobe）或「历史和任意连字」（Word）以开启该功能。

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="./images/dlig.dark.svg">
  <img src="./images/dlig.light.svg">
</picture>

* **全角、半角与比例宽度字形**（`fwid`、`hwid`、`pwid`）

  弯引号有全角、半角、比例（Adobe 误译为「等比宽度」）3种宽度的字形。中豆黑体默认使用半角弯引号；`fwid` 改用全角字形，`hwid` 改用半角字形，`pwid` 改用比例宽度字形。连接号和间隔号仍有全角、半角2种宽度的字形，但默认宽度不因引号的默认设置而改变。Adobe 软件可在「字形」面板中选择相应字形。

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="./images/fwid-hwid-pwid.dark.svg">
  <img src="./images/fwid-hwid-pwid.light.svg">
</picture>

* **破折号连字**（`ccmp`）

  将2个「—」（`U+2014`）组成一个完整的破折号，将3个「—」组成一个占3字宽的长横。默认开启。本功能仅处理破折号组合，不控制弯引号的宽度。

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="./images/ccmp.dark.svg">
  <img src="./images/ccmp.light.svg">
</picture>

* **标点挤压**（`kern`、`vkrn`）

  原字体用这两个功能压缩连续标点所占的空间。中豆黑体保留功能标签，但清空了查找列表；无论应用程序是否开启 `kern` 或 `vkrn`，字体本身都不会挤压标点。需要标点挤压时，请使用排版软件自身的标点挤压功能。

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="./images/kern.dark.svg">
  <img src="./images/kern.light.svg">
</picture>

  > 文本选自〔请颁行新式标点符号议案（修正案）〕

* **地区字形**（`locl`）

  陆规（`ZHS`）复用台规（`ZHT`）的居中标点查找，因此标记为陆规的文本默认采用居中标点。这里只共享 `locl` 查找；竖排字形等其他地区功能保持不变。将文本标记为港澳台、日文或韩文时，仍采用各自的地区字形。

  <source media="(prefers-color-scheme: dark)" srcset="./images/locl.dark.svg">
  <img src="./images/locl.light.svg">
</picture>

  > 文本选自1951年〔标点符号用法〕

* **斜杠0**（`zero`）

  将全角数字０更改为斜杠０︀（Adobe 称「斜线零」）字形。

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="./images/zero.dark.svg">
  <img src="./images/zero.light.svg">
</picture>

* **竖排字形**（`vert`）

  在竖排文本中使用相应的标点形式，默认开启。默认语言与陆规文本中的顿号、句号、叹号、逗号、句点、冒号、分号、问号保持居中；明确指定 VS01 时仍采用偏靠字形。其他地区的文本继续采用各自的竖排标点形式。

* **居中标点**（`cpct`、`ss01`）

  将顿号、句号、叹号、逗号、句点、冒号、分号、问号居中。两项功能仍为可选功能，并未被改成默认开启；陆规已通过 `locl` 默认获得相同的居中效果。其他语言仍可在软件 OpenType 功能菜单中选择「居中中日韩标点」风格组合（Adobe）或「样式集1」（Word）以开启该功能。

  将逗号、分号和引号的字形改为蝌蚪形。可在软件 OpenType 功能菜单中选择「蝌蚪逗号」风格组合（Adobe）或「样式集2」（Word）以开启该功能。

## 生成样张

首页样张的排版源码位于 [`demo/`](./demo/)，输出为 [`images/demo.png`](./images/demo.png)。在项目根目录运行：

```nu
nix develop -c nur demo preview # 构建字体并在浏览器中打开 HTML 样张
nix develop -c nur demo render  # 重新生成 images/demo.png
```

这些任务会先从原始字体生成中豆黑体，再以固定的 2560×1440 画布渲染并压缩图片。Nix flake 锁定 Nur、渲染工具和备用字体的版本。拉取请求中的样张若已过时，持续集成便会报错；推送到 `main` 后，持续集成则会在样张变化时自动创建 `docs: update generated demo` 提交，不变时不会提交。
